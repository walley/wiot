# Wiot Web Server Backend

Wiot is a lightweight web server backend designed for Internet of Things (IoT) applications. It provides a simple and efficient way to manage IoT devices and data.

## Features
- IoT Platform: Supports device communication and data management.
- Web-based Interface: Easily accessible through a browser.
- SQLite Database: Stores device data efficiently.
- Perl-based Backend: Ensures flexibility and reliability.

## Installation
To install Wiot, follow these steps:

1. Clone the repository:
   git clone https://github.com/walley/wiot.git

2. Navigate to the project directory:
   cd wiot

3. Install dependencies (ensure Perl and SQLite are installed):
   sudo apt-get install perl sqlite3

4. Run the server:
   perl server.pl

## Usage
- Access the web interface via http://localhost:8080
- Configure IoT devices through the provided API endpoints.
- Store and retrieve data using the integrated SQLite database.
